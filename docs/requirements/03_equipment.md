# 03 — 装備（杖・本・アイテム）

## 杖（武器）

### 概要
- プレイヤーの主要攻撃手段
- **1枠のみ**装備可能
- クールタイム（秒数）制で自動発動
- 強化可能（イベント・ショップ等で）

### 杖のパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | 杖の名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー |
| ダメージ | 固定ダメージ値 |
| CT | クールタイム（秒数） |
| 効果 | 追加効果（状態異常付与等） |
| 対象 | 単体 / 全体 / ランダム |

### 杖の例

| 名前 | ダメージ | CT | 効果 |
|---|---|---|---|
| 木の杖 | 5 | 2s | なし |
| カエデの杖 | 12 | 3s | なし |
| 棘の杖 | 8 | 2s | 毒付与（2/s × 3s） |
| 隕石の杖 | 30 | 7s | 全体攻撃 |

## 本（スキル）

### 概要
- スキル・魔法に相当する装備
- **5枠**装備可能（アイテムや休憩所で拡張可能）
- クールタイム（秒数）制で自動発動
- 冒険中に収集・入れ替え可能

### 本のパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | 本の名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー |
| 効果 | 発動時の効果（ダメージ・回復・バフ等、数値は固定） |
| CT | クールタイム（秒数） |
| 対象 | 自分 / 単体敵 / 全体敵 / 味方全体 |
| カテゴリ | 攻撃 / 回復 / 防御 / 補助 |

### 本の例

| 名前 | カテゴリ | CT | 効果 |
|---|---|---|---|
| 火球の書 | 攻撃 | 4s | 単体に15ダメージ |
| 吹雪の書 | 攻撃 | 6s | 全体に10ダメージ |
| 治癒の書 | 回復 | 5s | HP 15回復 |
| 障壁の書 | 防御 | 6s | シールド20付与 |
| 猛毒の書 | 攻撃 | 4s | 単体に毒（3/s × 5s） |
| 加速の書 | 補助 | 8s | 全装備の現在CTを2s短縮 |

## アイテム（レリック）

### 概要
- 常時パッシブ効果を持つ装備
- CT なし（取得した時点から常時有効）
- **所持数は無制限**（入手機会の頻度で調整）
- 冒険中に収集・蓄積

### アイテムのパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | アイテムの名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー |
| 効果 | 常時発動するパッシブ効果 |

### アイテムの例

| 名前 | 効果 |
|---|---|
| 力の腕輪 | 杖ダメージ +5 |
| 魔導書の栞 | 本ダメージ +20% |
| 再生の指輪 | 1sごとに HP 1回復 |
| 古びた懐中時計 | 全装備のCT 10%短縮 |
| 棘の鎧 | 被ダメージ時、攻撃者に3ダメージ |
