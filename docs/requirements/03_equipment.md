# 03 — 装備（杖・本・アイテム）

## 杖（武器）

### 概要
- プレイヤーの主要攻撃手段
- **1枠のみ**装備可能
- クールタイム制で自動発動

### 杖のパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | 杖の名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー（TBD） |
| 攻撃力 | 基本ダメージ値 |
| CT | クールタイム（ターン数） |
| 効果 | 追加効果（属性付与・状態異常等） |
| 対象 | 単体 / 全体 / ランダム |

### 杖の例

| 名前 | 攻撃力 | CT | 効果 |
|---|---|---|---|
| 木の杖 | 5 | 2 | なし |
| カエデの杖 | 12 | 3 | なし |
| 炎の杖 | 18 | 4 | 火属性ダメージ |
| 嵐の杖 | 30 | 6 | 全体・雷属性 |

## 本（スキル）

### 概要
- スキル・魔法に相当する装備
- **複数枠**装備可能（初期3枠）
- クールタイム制で自動発動
- 冒険中に収集・入れ替え可能

### 本のパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | 本の名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー |
| 効果 | 発動時の効果（ダメージ・回復・バフ等） |
| CT | クールタイム（ターン数） |
| 対象 | 自分 / 単体敵 / 全体敵 / 味方全体 |
| カテゴリ | 攻撃 / 回復 / 防御 / 補助 |

### 本の例

| 名前 | カテゴリ | CT | 効果 |
|---|---|---|---|
| 火炎の書 | 攻撃 | 5 | 全体に火属性ダメージ |
| 治癒の書 | 回復 | 4 | HPを一定量回復 |
| 障壁の書 | 防御 | 6 | 3ターンシールド付与 |
| 猛毒の書 | 攻撃 | 4 | 単体に毒付与 |
| 加速の書 | 補助 | 5 | 全装備のCTを1短縮 |

---

## アイテム（レリック）

### 概要
- 常時パッシブ効果を持つ装備
- CT なし（取得した時点から常時有効）
- 冒険中に収集・蓄積（入れ替えは基本なし、TBD）

### アイテムのパラメータ

| パラメータ | 説明 |
|---|---|
| 名前 | アイテムの名称 |
| レアリティ | コモン / アンコモン / レア / レジェンダリー |
| 効果 | 常時発動するパッシブ効果 |

### アイテムの例

| 名前 | 効果 |
|---|---|
| 知恵の眼鏡 | スキル（本）ダメージ +15% |
| 鉄のお守り | 防御力 +10 |
| 炎のルビー | 火属性ダメージ +20% |
| 再生の指輪 | ターン終了時 HP 2% 回復 |
| 古びた懐中時計 | 全装備のCT -1（最低1） |
