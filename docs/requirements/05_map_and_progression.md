# 05 — マップ・進行構造

## 章構成

1ランは複数の**章（Chapter）**で構成される。

| 章 | テーマ（仮） | ノード数目安 | ボス |
|---|---|---|---|
| 第1章 | 始まりの草原 | 6〜8 | 草原のボス |
| 第2章 | 深き森 | 7〜9 | 森のボス |
| 第3章 | 灼熱の洞窟 | 8〜10 | 洞窟のボス |
| 最終章 | 忘却の塔 | 9〜11 | 最終ボス |

※ 章数・テーマは仮。段階的に拡張予定。

## マップ構造

各章のマップは**Slay the Spire型のノード選択式**を採用する。

```
[START]
  ├── [戦闘] ── [イベント] ── [戦闘]
  │                              │
  ├── [ショップ] ── [戦闘] ─────┤
  │                              │
  └── [休憩] ── [宝箱] ── [戦闘]┘
                                 │
                              [BOSS]
```

- 開始ノードから分岐し、プレイヤーが進路を選ぶ
- 各ノードは1回のみ通過
- 最終的にボスノードに合流する

## ノードの種類

| ノード | アイコン | 内容 |
|---|---|---|
| **戦闘** | ⚔️ | 通常の敵と戦闘。勝利で報酬（杖/本/アイテム/ゴールド） |
| **エリート戦闘** | 💀 | 強敵。高レアリティの報酬 |
| **ボス** | 👑 | 章のボス。撃破で次の章へ進む |
| **ショップ** | 🛒 | ゴールドで杖・本・アイテムを購入。不要な装備を売却 |
| **休憩** | 🏕️ | HPを一定割合回復。本の枠拡張の可能性あり |
| **イベント** | ❓ | ランダムイベント（下記参照） |
| **宝箱** | 🎁 | 杖・本・アイテムのいずれかを無条件で獲得 |

## イベントの種類

| イベント | 内容 |
|---|---|
| 本入手 | 本を1冊獲得 |
| 武器強化 | 現在の杖を強化（ダメージUP or CT短縮） |
| アイテム入手 | アイテム（レリック）を1つ獲得 |
| 休憩所 | HP回復。本の枠拡張の選択肢がある場合も |
| 商人 | ゴールドで売買 |
| パーティーメンバー加入 | 仲間が1人加入（一定CTで1種の行動を繰り返す） |

## 報酬の提示方式
- 戦闘勝利後: 3択（杖/本/アイテムからランダムに提示、1つ選択）
- エリート戦闘: レア以上確定の3択
- 宝箱: 1つ自動獲得

## 章クリア時
- ボス撃破報酬（高レアリティ装備 or 冒険の書関連）
- 最大HPの一定量回復
- 次の章のマップが生成される
