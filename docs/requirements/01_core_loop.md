# 01 — コアループ

## 1ランの流れ

```
冒険開始（書庫から書を選択）
  │
  ▼
┌─────────────────────────┐
│  マップ画面（章）        │
│  ├─ ノード選択           │
│  │   ├─ 戦闘             │
│  │   ├─ イベント         │
│  │   ├─ 休憩（HP回復）   │
│  │   ├─ ショップ         │
│  │   └─ 宝箱             │
│  │                       │
│  ▼                       │
│  ボス戦 → 次の章へ       │
└─────────────────────────┘
  │
  ▼
死亡 or 最終ボス撃破
  │
  ▼
リザルト → 冒険の書を書庫に保管
  │
  ▼
次の冒険へ
```

## ラン内で得られるもの
- 杖（武器）
- 本（スキル）
- アイテム（レリックパッシブ）
- ゴールド（ショップ用、ラン内限定）
- 経験値 → レベルアップ（ラン内限定）
- 記憶の断片 → 冒険の書の素材

## ラン間で持ち越せるもの（メタ進行）
- 冒険の書（書庫に保管）
- 図鑑（出会った敵・杖・本・アイテムの記録）
- 書庫スロット拡張の進捗
