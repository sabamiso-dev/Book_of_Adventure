# 06 — プレイヤーステータス

## 基本ステータス

| ステータス | 説明 | 初期値（TBD） |
|---|---|---|
| **HP** | 体力。0になると死亡 | 80 |
| **最大HP** | HPの上限 | 80 |

- ステータスは**HPのみ**
- 攻撃力・防御力・魔力といった計算用ステータスは存在しない
- ダメージは装備に記載された**固定値**がそのまま適用される

## レベルシステム
- レベルシステムは**なし**
- キャラクターの成長は装備（杖・本）の収集とアイテムの蓄積で表現する
- 最大HPの増加手段は休憩所・イベント・アイテムなどで用意（TBD）

## パーティーメンバー
- 最大**4人**（主人公含む）
- イベントで加入。一度加入すると**枠は空かない**
- 主人公とは異なり、**一定CTで1種類の行動のみ**を自動で繰り返す
- パーティーメンバーにも**HPがあり**、HP0で**死亡状態（棺桶）**になる
- 蘇生ポイント等で復活可能
- 主人公が死亡 = ゲームオーバー（メンバー全滅ではゲームオーバーにならない）
