# 06 — プレイヤーステータス

## 基本ステータス

| ステータス | 説明 | 初期値（TBD） |
|---|---|---|
| **HP** | 体力。0になると死亡 | 100 |
| **最大HP** | HPの上限 | 100 |
| **攻撃力** | 杖の物理ダメージに加算 | 10 |
| **魔力** | 本のスキルダメージに加算 | 10 |
| **防御力** | 被ダメージを軽減 | 5 |

## レベルシステム（ラン内限定）
- 戦闘勝利で経験値を獲得
- レベルアップ時にステータスが上昇
- レベルアップ時のステータス配分は自動（TBD: 手動選択にするか）
- 死亡時にレベルはリセットされる

## 状態異常（TBD）

| 状態異常 | 効果 |
|---|---|
| 毒 | ターン終了時にダメージ |
| 火傷 | ターン終了時にダメージ（毒より高ダメ・短持続） |
| 凍結 | 次の行動をスキップ |
| 弱体 | 攻撃力/魔力が一定割合低下 |
