# 02 — 戦闘システム

## 基本方針
- **ターン制・オートバトル**
- プレイヤーは戦闘前に装備を整え、戦闘中は自動で進行
- 杖と本は**クールタイム（CT）制**で自動発動

## 装備スロット

| スロット | 枠数 | 発動方式 | 役割 |
|---|---|---|---|
| 杖（武器） | **1枠** | CT制・自動発動 | 基本攻撃手段 |
| 本（スキル） | **複数枠**（初期3枠、TBD） | CT制・自動発動 | スキル・魔法 |
| アイテム（レリック） | 複数枠（TBD） | 常時パッシブ | 永続的な強化効果 |

## クールタイム（CT）

- 各装備に固有のCT値（ターン数）が設定されている
- 戦闘開始時、全装備のCTは**0（即発動可能）**
- 発動後、CT値分のターン経過で再度発動可能
- CTが0になった装備は次のターンで自動発動

### CT例

| 装備 | CT | 効果 |
|---|---|---|
| カエデの杖 | 3 | 単体に物理ダメージ |
| 火炎の書 | 5 | 全体に火属性ダメージ |
| 治癒の書 | 4 | HP回復 |
| 障壁の書 | 6 | 3ターンシールド付与 |

## 1ターンの流れ

```
1. ターン開始
   └─ 全装備のCTカウンタ -1

2. プレイヤーフェイズ
   ├─ 杖が発動可能 → 杖攻撃
   └─ 本をスロット順にチェック → 発動可能な本を順次発動

3. 敵フェイズ
   └─ 敵の行動（敵ごとに固有パターン）

4. ターン終了
   └─ 状態異常・バフ/デバフの経過処理
```

## 戦闘の勝敗条件
- **勝利**: 敵を全滅させる
- **敗北**: プレイヤーのHPが0になる

## プレイヤーの戦略要素
戦闘自体はオートだが、以下が戦略となる：

1. **杖の選択** — 短CT高頻度 vs 長CT高威力
2. **本の組み合わせ** — CTをずらして毎ターン何か発動するよう調整
3. **アイテムによるシナジー** — 特定属性強化 + 対応する本を複数積む等
4. **レベル・ステータス配分**（TBD）
