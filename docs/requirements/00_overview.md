# 00 — ゲーム概要

## タイトル（仮）
**冒険の書（Book of Adventure）**

## ジャンル
2D ローグライク × オートバトル

## コンセプト
> 杖と本を携え、冒険の記憶を書に刻む。
> 死しても書は残り、次の冒険者へ受け継がれる。

プレイヤーは冒険者として章仕立てのマップを進み、道中で杖・本・アイテムを収集してビルドを構築する。戦闘はオートで進行し、プレイヤーの事前準備（装備選択・ビルド構築）が勝敗を決める。

死亡するとレベル・装備は失われるが、**冒険の書（メタ進行資産）**は書庫に残り、次の冒険を少しずつ有利にしていく。

## ゲームの柱

| 柱 | 説明 |
|---|---|
| **オートバトル** | 杖と本がクールタイム制で自動発動。戦闘前の準備が戦略 |
| **ビルド構築** | 杖1本＋複数の本＋アイテム（レリック）の組み合わせでシナジーを狙う |
| **ローグライク進行** | 死亡でリセット。毎回異なるマップ・報酬で新鮮な体験 |
| **冒険の書（メタ進行）** | 冒険で得た「書」が永続資産。書庫が充実するほど有利に |
