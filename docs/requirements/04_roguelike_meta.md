# 04 — ローグライク要素・メタ進行

## ローグライク要素

### 死亡時のリセット（パーマデス）
以下はラン内限定で、死亡時にすべて失われる：

| 要素 | 説明 |
|---|---|
| レベル | ラン内で戦闘経験値により上昇 |
| 杖 | 装備中の杖 |
| 本 | 装備中の本すべて |
| アイテム | 所持アイテムすべて |
| ゴールド | ショップ用通貨 |
| マップ進行度 | 次のランは第1章から |

### ランダム性
- マップのノード配置は毎回ランダム生成
- 戦闘報酬（杖・本・アイテム）はランダム抽選
- ショップの品揃えはランダム
- イベントの内容はランダム（プールから抽選）

## メタ進行（ラン間の永続要素）

### 冒険の書システム

#### 記憶の断片
- 戦闘勝利・イベント・ボス撃破などで「記憶の断片」を獲得
- ランの終了時（死亡 or クリア）、集めた断片が**冒険の書**として書庫に保管される

#### 冒険の書の効果
- 1冊につき1つのパッシブ効果を持つ
- 次のラン開始時、書庫から**一定枠数だけ**持ち込める

#### 冒険の書の例

| 書名 | 効果 |
|---|---|
| 炎の記憶 | 火属性ダメージ +10% |
| 盾騎士の記録 | 初期防御力 +5 |
| 商人の知恵 | ショップ価格 10% 割引 |
| 探索者の直感 | マップでノード情報が1つ先まで見える |
| 薬師の知識 | 回復効果 +15% |

### 書庫

| 要素 | 説明 |
|---|---|
| 保管数 | 無制限（集めた書はすべて保管） |
| 持ち込み枠 | 初期2枠（拡張可能） |
| 枠の拡張条件 | 特定の実績達成・ボス初回撃破など |

### 図鑑
- 出会った敵・杖・本・アイテム・冒険の書を記録
- 閲覧専用（直接的なゲーム効果はなし、TBD）

---

## メタ進行のバランス方針
- 冒険の書は「少し有利になる」程度に留める
- 書を集めなくてもクリアは可能（プレイヤースキル＝ビルド構築力で突破できる）
- メタ進行は「選択肢が増える」方向を重視（単純な数値インフレを避ける）
